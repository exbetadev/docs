# Credits

ExBeta is built on contributions from the Roblox exploit development community and relies on the following open-source projects:

## Dependencies

- **Luau** — Roblox's Luau runtime and compiler.
- **cURL** — HTTP client library.
- **Crypto++** — Cryptographic functions.
- **zstd** — Compression.
- **nlohmann/json** — JSON parsing.
- **imgui** — UI framework.
