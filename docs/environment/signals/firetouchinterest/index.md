# firetouchinterest

Simulates a touch between two parts.

```lua
firetouchinterest(part: Instance, interest: Instance, state: number): ()
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `part` | `Instance` | The touching part. |
| `interest` | `Instance` | The TouchInterest instance. |
| `state` | `number` | Pass state flag. |

## Example

```lua
firetouchinterest(part, interest, 0)
```
