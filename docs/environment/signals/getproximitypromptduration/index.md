# getproximitypromptduration

Returns the hold duration of a ProximityPrompt.

```lua
getproximitypromptduration(prompt: Instance): number
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `prompt` | `Instance` | The ProximityPrompt to read. |

## Returns

| Type | Description |
| --- | --- |
| `number` | Hold duration in seconds. |

## Example

```lua
print(getproximitypromptduration(prompt))
```
