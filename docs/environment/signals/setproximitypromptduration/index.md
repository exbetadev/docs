# setproximitypromptduration

Sets the hold duration of a ProximityPrompt.

```lua
setproximitypromptduration(prompt: Instance, seconds: number): ()
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `prompt` | `Instance` | The ProximityPrompt to modify. |
| `seconds` | `number` | Hold time in seconds. |

## Example

```lua
setproximitypromptduration(prompt, 0)
```
