# fireproximityprompt

Triggers a ProximityPrompt as though it were used.

```lua
fireproximityprompt(prompt: Instance): ()
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `prompt` | `Instance` | The ProximityPrompt to trigger. |

## Example

```lua
fireproximityprompt(prompt)
```
