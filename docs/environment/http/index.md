# Http

Perform HTTP requests and inspect responses.

| Function | Description |
| --- | --- |
| [`HttpGet`](httpget/index.md) | Performs a GET request and returns the response body. |
| [`HttpPost`](httppost/index.md) | Performs a POST request and returns the response body. |
| [`request`](request/index.md) | Performs a fully configurable HTTP request. |
| [`request response table`](request-response-table/index.md) | The table returned by `request`. |
