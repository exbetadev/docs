# WebSocket

Open WebSocket connections from the client.

| Function | Description |
| --- | --- |
| [`WebSocket.connect`](websocket-connect/index.md) | Opens a WebSocket connection and returns a client object. |
| [`WebSocket.OnMessage`](websocket-onmessage/index.md) | Fires whenever a message arrives. |
| [`WebSocket.OnClose`](websocket-onclose/index.md) | Fires when the connection closes. |
| [`WebSocket.Send`](websocket-send/index.md) | Sends a text message over the socket. |
| [`WebSocket.Close`](websocket-close/index.md) | Closes the connection. |
