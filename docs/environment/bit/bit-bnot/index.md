# bit.bnot

Bitwise NOT.

```lua
bit.bnot(value: number): number
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `value` | `number` | The value to invert. |

## Returns

| Type | Description |
| --- | --- |
| `number` | Result. |

## Example

```lua
print(bit.bnot(0)) -- 4294967295
```
