# bit.rol

Rotates bits left.

```lua
bit.rol(value: number, count: number): number
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `value` | `number` | Value to rotate. |
| `count` | `number` | Bit positions to rotate. |

## Returns

| Type | Description |
| --- | --- |
| `number` | Rotated result. |

## Example

```lua
print(bit.rol(1, 1)) -- 2
```
