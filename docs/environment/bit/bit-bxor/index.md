# bit.bxor

Bitwise XOR.

```lua
bit.bxor(...: number): number
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `...` | `number` | Values to XOR together. |

## Returns

| Type | Description |
| --- | --- |
| `number` | Result. |

## Example

```lua
print(bit.bxor(0xFF, 0x0F)) -- 240
```
