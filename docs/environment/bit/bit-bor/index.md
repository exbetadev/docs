# bit.bor

Bitwise OR.

```lua
bit.bor(...: number): number
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `...` | `number` | Values to OR together. |

## Returns

| Type | Description |
| --- | --- |
| `number` | Result. |

## Example

```lua
print(bit.bor(0xF0, 0x0F)) -- 255
```
