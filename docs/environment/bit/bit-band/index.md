# bit.band

Bitwise AND.

```lua
bit.band(...: number): number
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `...` | `number` | Values to AND together. |

## Returns

| Type | Description |
| --- | --- |
| `number` | Result. |

## Example

```lua
print(bit.band(0xF0, 0x0F)) -- 0
```
