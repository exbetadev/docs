# Actor

Run code in actor contexts and communicate across threads.

| Function | Description |
| --- | --- |
| [`getactors`](getactors/index.md) | Returns every Actor in the current DataModel. |
| [`run_on_actor`](run-on-actor/index.md) | Runs Luau code inside an actor's execution context. |
| [`isparallel`](isparallel/index.md) | Checks whether the current execution context is parallel. |
| [`create_comm_channel`](create-comm-channel/index.md) | Creates a cross-thread communication channel. |
| [`get_comm_channel`](get-comm-channel/index.md) | Retrieves an existing communication channel by identifier. |
