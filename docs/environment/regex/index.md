# Regex

Match and replace patterns using ECMAScript regex.

| Function | Description |
| --- | --- |
| [`Regex.new`](regex-new/index.md) | Compiles a regular expression. |
| [`Regex:Match`](regex-match/index.md) | Finds the first match and returns its captures. |
| [`Regex:MatchMany`](regex-matchmany/index.md) | Finds all matches and returns their captures. |
| [`Regex:Replace`](regex-replace/index.md) | Replaces every match with the replacement string. |
| [`Regex.Escape`](regex-escape/index.md) | Escapes special regex characters so the string matches literally. |
