# mousemoveabs

Moves the cursor to screen coordinates.

```lua
mousemoveabs(x: number, y: number): ()
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `x` | `number` | Screen X coordinate. |
| `y` | `number` | Screen Y coordinate. |

## Example

```lua
mousemoveabs(500, 400)
```
