# mousemoverel

Moves the cursor by an offset.

```lua
mousemoverel(x: number, y: number): ()
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `x` | `number` | Horizontal offset in pixels. |
| `y` | `number` | Vertical offset in pixels. |

## Example

```lua
mousemoverel(10, 0)
```
