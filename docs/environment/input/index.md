# Input

Simulate keyboard and mouse input.

| Function | Description |
| --- | --- |
| [`isrbxactive`](isrbxactive/index.md) | Checks whether the Roblox window is currently focused. |
| [`keypress`](keypress/index.md) | Holds a key down. |
| [`keytap`](keytap/index.md) | Presses and releases a key. |
| [`keyrelease`](keyrelease/index.md) | Releases a held key. |
| [`mouse1click`](mouse1click/index.md) | Clicks the left mouse button. |
| [`mouse1press`](mouse1press/index.md) | Holds the left mouse button down. |
| [`mouse1release`](mouse1release/index.md) | Releases the left mouse button. |
| [`mouse2click`](mouse2click/index.md) | Clicks the right mouse button. |
| [`mouse2press`](mouse2press/index.md) | Holds the right mouse button down. |
| [`mouse2release`](mouse2release/index.md) | Releases the right mouse button. |
| [`mousemoveabs`](mousemoveabs/index.md) | Moves the cursor to screen coordinates. |
| [`mousemoverel`](mousemoverel/index.md) | Moves the cursor by an offset. |
| [`mousescroll`](mousescroll/index.md) | Scrolls the mouse wheel. |
| [`messagebox`](messagebox/index.md) | Shows a native message box. |
| [`setclipboard`](setclipboard/index.md) | Copies text to the system clipboard. |
