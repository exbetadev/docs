# Crypt

Hash, encrypt, compress and encode data.

| Function | Description |
| --- | --- |
| [`base64_encode`](base64-encode/index.md) | Encodes binary data to base64. |
| [`base64_decode`](base64-decode/index.md) | Decodes base64 back to bytes. |
| [`crypt.hash`](crypt-hash/index.md) | Computes a hash of the input data. |
| [`crypt.encrypt`](crypt-encrypt/index.md) | AES-CBC encryption. |
| [`crypt.decrypt`](crypt-decrypt/index.md) | AES-CBC decryption. |
| [`crypt.generatekey`](crypt-generatekey/index.md) | Generates a random 32-byte encryption key. |
| [`crypt.generatebytes`](crypt-generatebytes/index.md) | Generates random bytes. |
| [`crypt.random`](crypt-random/index.md) | Returns a random integer in the range `[min, max]`. |
| [`crypt.hmac`](crypt-hmac/index.md) | Computes an HMAC signature. |
| [`crypt.lz4compress`](crypt-lz4compress/index.md) | LZ4 compression. |
| [`crypt.lz4decompress`](crypt-lz4decompress/index.md) | LZ4 decompression. |
| [`getfunctionhash`](getfunctionhash/index.md) | Computes a hash representing the function's bytecode. |
