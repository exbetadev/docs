# Reflection

Read and write hidden properties.

| Function | Description |
| --- | --- |
| [`isscriptable`](isscriptable/index.md) | Checks whether a property can be accessed from scripts. |
| [`setscriptable`](setscriptable/index.md) | Makes a property scriptable or non-scriptable. |
| [`gethiddenproperty`](gethiddenproperty/index.md) | Reads a hidden or internal property. |
| [`sethiddenproperty`](sethiddenproperty/index.md) | Writes a hidden or internal property. |
| [`gethiddenproperties`](gethiddenproperties/index.md) | Returns all hidden properties of an instance. |
| [`getproperties`](getproperties/index.md) | Returns all scriptable and hidden properties. |
| [`getcallbackvalue`](getcallbackvalue/index.md) | Reads a callback property, such as a BindableFunction callback. |
| [`setcallbackvalue`](setcallbackvalue/index.md) | Writes a callback property. |
| [`getpcd`](getpcd/index.md) | Returns property change descriptor metadata. |
