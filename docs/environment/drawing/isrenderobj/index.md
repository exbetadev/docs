# isrenderobj

Checks whether a value is a drawing object.

```lua
isrenderobj(value: any): boolean
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `value` | `any` | The value to test. |

## Returns

| Type | Description |
| --- | --- |
| `boolean` | `true` when the value is a DrawingObject. |

## Example

```lua
print(isrenderobj(line)) -- true
```
