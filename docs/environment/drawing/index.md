# Drawing

Draw 2D shapes overlaid on the game view.

| Function | Description |
| --- | --- |
| [`Drawing.new`](drawing-new/index.md) | Creates a new drawing object of the specified type. |
| [`Drawing.Fonts`](drawing-fonts/index.md) | A table mapping font names to font IDs for Text drawings. |
| [`DrawingObject:Remove`](drawingobject-remove/index.md) | Destroys the drawing and releases its resources. |
| [`DrawingObject:Destroy`](drawingobject-destroy/index.md) | Alias for `Remove`. |
| [`Line properties`](line-properties/index.md) | Properties for Line drawings. |
| [`Circle properties`](circle-properties/index.md) | Properties for Circle drawings. |
| [`Square properties`](square-properties/index.md) | Properties for Square (rectangle) drawings. |
| [`Quad properties`](quad-properties/index.md) | Properties for Quad drawings. |
| [`Triangle properties`](triangle-properties/index.md) | Properties for Triangle drawings. |
| [`Image properties`](image-properties/index.md) | Properties for Image drawings. |
| [`Text properties`](text-properties/index.md) | Properties for Text drawings. |
| [`cleardrawcache`](cleardrawcache/index.md) | Removes all drawing objects at once. |
| [`getrenderproperty`](getrenderproperty/index.md) | Reads a drawing property. |
| [`setrenderproperty`](setrenderproperty/index.md) | Writes a drawing property. |
| [`isrenderobj`](isrenderobj/index.md) | Checks whether a value is a drawing object. |
