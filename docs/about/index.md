# About ExBeta

ExBeta is a Roblox script executor designed for developers who need low-level control over game state and runtime behavior.

## Features

- **Function Manipulation** — Hook, clone, and inspect functions at runtime.
- **Metatable Control** — Read and modify protected metatables.
- **Debug Introspection** — Access upvalues, constants, prototypes, and the call stack.
- **Filesystem Access** — Read and write files in a sandboxed workspace.
- **Networking** — HTTP requests and WebSocket connections.
- **Cryptography** — Hash, encrypt, compress, and encode data.
- **Drawing API** — Render 2D overlays on the game viewport.
- **Input Simulation** — Programmatic keyboard and mouse control.
- **Script Analysis** — Inspect loaded scripts and their bytecode.
- **Signal Control** — Fire and intercept Roblox signals.

## Environment

The executor provides a Luau environment extending the standard Roblox API with 208 additional functions across 20 libraries.

All functions are documented in the [Environment](../environment/index.md) section.
